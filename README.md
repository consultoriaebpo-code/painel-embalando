# Painel de vendas — Embalando Festas (CONPEL)

Página do painel com login e senha.

- **Endereço:** https://consultoriaebpo-code.github.io/painel-embalando/
- **O que fica aqui:** só a página (tela de login, tela de usuários e o painel). Não há vendas, usuários nem senhas neste repositório.
- **Onde ficam os dados:** no Google, no projeto Apps Script "CONPEL - PAINEL EMBALANDO FESTAS (SITE COM LOGIN)", que confere login e senha e entrega as vendas do ano (geradas todo dia pelo CONPEL MOTOR V2).
- **Por que fora do Google:** a página hospedada no Google dá erro quando o navegador tem várias contas Google abertas. Aqui ela conversa com o Apps Script sem usar a conta Google de quem acessa.

Não edite `index.html` à mão: ele é gerado a partir do código do painel.
